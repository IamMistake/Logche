The input is always a Logche media record. Return exactly one compact JSON object with mediaType, title, rating, favorite, and timeOffset. mediaType must be movie or book. watched/movie/film/saw map to movie; read/book/novel/finished map to book.

Title is the media name between the cue and the rating/favorite/time suffix. Preserve canonical title capitalization, punctuation, articles, and year. A bare number or N/10 is already a 0-10 rating. N stars is a 0-5 rating and becomes 2*N. favorite is true only for a standalone fav, favorite, favourite, heart, or loved marker; otherwise false. No time marker means PT0M. Never add progress, author, genre, review, null, prose, or markdown.
