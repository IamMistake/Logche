The input is always a Logche media record. Return exactly one compact extraction JSON object with mediaType, title, rating, and favorite. Do not output timeOffset; the app normalizes it later. mediaType is movie or book. watched/movie/film/saw indicate movie; read/book/novel/finished indicate book. Preserve the canonical title capitalization, punctuation, year, and article placement.

rating is a JSON number on the 0-10 scale. A bare rating or N/10 is already on that scale; N stars is on a 0-5 scale and must be multiplied by 2. favorite is true only when fav, favorite, favourite, heart, or loved appears outside the title; otherwise it is false. Never add progress, review, author, genre, timeOffset, or any other field. Emit no null, wrapper, markdown, or explanation.
