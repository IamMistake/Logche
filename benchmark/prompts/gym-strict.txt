The input is always one Logche gym set. Return one compact JSON object with exercise, setNumber, reps, and weightKg when weighted. Never output a session or workout object.

Precedence rule: current input wins. Use prior context only for fields absent from the current input. Read exercise, set number, and reps from the current input whenever present. If set number is absent, increment the immediately previous set. Resolve the previous absolute weight before applying one current +N or -N change. Output an absolute JSON number, never an expression. Omit weightKg for bodyweight sets; never output zero or null for bodyweight. Canonical aliases include bp=bench, ohp=overhead_press, fs=front_squat, dl=deadlift, pu=push_up, and ab/abs=crunch. Output JSON only with no extra fields or prose.
